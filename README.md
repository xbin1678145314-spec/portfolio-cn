# 王翔彬｜国内游戏美术作品集

这是一版与海外求职网站明显区分的国内版作品集。

## 视觉方向
- 海外版：深色 / 荧光绿 / 国际化简洁展示
- 国内版：米白 / 深蓝 / 橙色强调，信息密度更高
- 国内版更突出：项目职责、商业数据、Unity落地、移动端优化和工作经历

## 网站结构
1. 首页：求职定位 + 5年经验 + 商业成绩
2. 代表项目：
   - My Tiny Tower
   - Idle Oil Well
   - Cat Train Tycoon
   - Sunshine Power（文字商业案例）
   - Shooting Range Inc（文字商业案例）
3. 移动端优化案例：约300 → 约150 Batches
4. 技能与生产能力
5. 工作经历
6. 联系方式 + 中文简历

## GitHub Pages
建议单独建一个国内版仓库，例如：
- `portfolio-cn`
- `game-art-cn`

上传本 ZIP 解压后的所有文件到仓库根目录，然后开启 GitHub Pages。

如果希望海外版和国内版共用一个域名，也可以后续做：
- `/portfolio/` 海外版
- `/portfolio-cn/` 国内版
